# Daniel Werner – interaktywne CV

Strona-kampania: odwiedzający jest „leadem”, a w rogu widzi na żywo zdarzenia (w stylu GA4 DebugView), lead score i etap lejka. Nic nie jest wysyłane – śledzenie działa tylko w przeglądarce.

- Personalizacja jak w ABM: `?dla=NazwaFirmy` (np. `index.html?dla=Przelewy24`) zmienia nagłówek, temat maila i tytuł karty.
- Demo „jeden komunikat, cztery kanały”: wpisz komunikat i kliknij „Uporządkuj”.
- Przycisk „Jestem botem ATS” przełącza na czysty tekst CV.

Jeden plik `index.html` bez budowania. Hosting: GitHub Pages (branch `main`, katalog główny).
